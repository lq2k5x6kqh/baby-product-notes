# 【妇幼康复】如何早期发现婴幼儿感觉处理障碍

> 更新时间：2026-09-16 (UTC+8)

近期的诊疗过程中，我们发现家长经常有这样的困扰，“总觉得我家孩子到哪都不自在，但又不明白为什么”，其实很可能是感觉处理障碍引起的。现由福建省妇幼保健院/福建省儿童医院康复科李民主任作业治疗团队给大家分享一些感觉处理障碍的早期表征和症状，帮助家长们早期发现孩子感觉处理障碍。

我们先来看看什么是感觉处理障碍。

01

感觉处理障碍

感觉处理障碍是指人体的外部环境和内部环境的信号没有以正常的方式被大脑处理。好比在公路上有很多汽车，它们相互碰撞，无法快速、平稳到达目的地。感觉处理障碍就是这样。

那我们来看一下感觉处理障碍在婴幼儿时期的早期征象都有哪些，为什么会出现这样的表现呢？发现异常后家长们该如何应对呢？

02

早期征兆及应对策略—婴儿期

**【早期征兆及潜在原因】**

1.  当我们把新生儿带回家时，孩子看起来非常不舒服

小婴儿刚出生来到我们生活的环境中时，视、听、嗅等多种感觉信息都与妈妈肚子里的环境大有不同，如果对这些感觉的处理和适应能力不足，孩子常常会表现为哭闹不止。

2.  孩子表现出较高或较低的肌肉张力

如果你发现孩子的身体过紧或过软，可能是体位变化时激活了前庭系统，诱发了孩子某些原始反射，如果这种原始反射到了该消失的月龄仍存在，则考虑病理性因素，此时妈妈们要警惕，及时就医。

3.  婴儿拒绝俯卧

  A．俯卧时的前庭觉输入较多，如果孩子存在前庭觉调节异常可能会讨厌趴着；

  B．如果您的孩子存在触觉调节异常，趴在他不喜欢的平面上也使他感到焦虑。

4.  被触摸时感到不适，需要不断地动来动去才能感到舒缓，难以喂养、难以含住乳头、过渡到固体食物困难
此时很可能是孩子的触觉系统出了问题。
5.  适龄爬行阶段发育异常（完全跳过该阶段、感到不适、动作不流畅）
触觉防御、原始反射整合不良都会引起以上问题。 

**【应对策略】**

1.  可给孩子做些关节挤压

2.  使用触觉刷或布片刷擦身体（根据年龄提供合适压力大小）

3.  盖厚被子、增加咀嚼和吸吮的活动

4.  如果孩子出现不把东西放在嘴里这个信号时，他们是在避免口部感觉输入，此时可以把手指放入孩子口中轻轻按摩，这是使口腔结构脱敏最简单有效的方法。

03

早期征兆及应对策略—幼儿期

**【早期征兆及潜在原因】**

     1.  跳过了某些发育阶段或发育延迟、运动时感到痛苦不安

如果你的孩子1岁半了还不会跳，或是走路晚，运动时可能会感到痛苦不安，很可能存在重力不安全感或双侧统合障碍。

2.  过渡到学步阶段时，动作很笨拙，平衡能力很差

原始反射整合、姿势平衡控制不良、预测性活动能力不足、双侧统合障碍等都可能造成这些问题。

3.  注意力差，适龄活动持续时间短

孩子到了三岁时，会努力参与适龄活动，并投入适量注意力。三岁的孩子，他们应该能够参加大约3分钟的适龄活动，如果达不到，可能与感觉系统有关。

4.  存在严重的分离焦虑症，情绪波动大，经常无缘无故大发脾气；对不同的声音、质感过于敏感或不够敏感；在新的环境和新的情况下完全崩溃

以上几个表现可能与他们的感觉系统有关，因为他们的身体无法正确处理感觉信息，无法适应环境的变化。新环境中会有不同的视觉、听觉、嗅觉、等等未知的感觉信息。也许是灯光太亮、也许是声音刺耳，也许在房间不同区域或不同位置有声音，也许是浓烈的气味，导致孩子无法处理，因为同时有太多信息进入他们的大脑。

可能他们的身体渴望在新的地方跑来跑去，但种种信息告诉他们这里不安全，他们却不能理解，随之而来的是崩溃、暴躁。

**【应对策略】**
1.  提前告知、做好思想准备工作

如果年龄稍大些的孩子，可以尝试讲一个社交故事，以便他们直观地看到或知道在新环境中会发生什么，并讨论这些先入为主的观念，以及什么样的行为可以被接受。

      2.  增加本体感觉输入

进入新环境前，可以给孩子很多重体力作业活动（推、拉等），目的是增加本体感觉的输入，因为本体感觉起到抑制作用，他可以凌驾于新环境产生的所有感觉失调之上，可以帮助他们调节感觉系统，进而帮助孩子掌控全局。

04

温馨提示

如果您发现孩子有上述情况，可以向专业的作业治疗师寻求帮助。作业治疗师会帮助你分析孩子问题的根源，利用有效的感觉刺激输入来帮助孩子重新建立自我调节能力。
